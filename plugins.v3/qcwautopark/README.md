# 抢车位助手

支持 MoviePilot V2/V3，通过游戏 HTTP 接口定时贴条、收车和停车。无需浏览器、Browserless 或油猴常驻。

## 默认行为

| 配置 | 默认值 | 判定 |
| --- | --- | --- |
| 检查间隔 | 5分钟 | 固定间隔执行，上轮未结束时跳过重入 |
| 自动贴条 | 开启 | 只操作自己私家车位上他人的车 |
| 贴条预估收益阈值 | 1000 | **≥1000**，包含1000 |
| 收车基础收益阈值 | 2000 | **>2000**，正好2000不收 |
| 停车场主人等级上限 | 3 | **≤3** |
| 停车场主人金币上限 | 3000 | **≤3000** |
| HTTP请求间隔 | 10秒 | 上个请求完成后至少等待10秒，可调高至300秒 |

每轮先贴条，再收车，再把空闲车辆停入符合条件的空闲私家车位。贴条开关、两种收益阈值、主人等级/金币上限及定时间隔均可设置。

停车场主人的等级与金币必须同时满足。3级、3000金币符合条件；4级、100金币或2级、3001金币都不符合。排除自己的车位、爱心车位、已占用车位及等级/金币缺失的玩家。没有符合条件的车位时保留空闲，等待下轮，不会放宽条件。每轮最多考察100个候选车位。

贴条与收车遵守服务端的最短停车时间，当前公开规则分别为5分钟和10分钟。收益按网页预估收益口径计算：服务端时间、完整分钟、车型每分钟收益及单车收益封顶；场景加成不计入阈值，实际到账取自接口。支持限时车型收益。

## 认证：复用MP站点Cookie

1. 在 MoviePilot 站点管理中保存躺平 PT 主站（www.tangpt.top 或 tangpt.top）的有效 Cookie。
2. 在插件配置的“认证使用的 MP 主站”中选择该站点。只有一个有效匹配站点时，可以自动匹配。
3. 设置阈值，勾选“保存后立即执行一次”，查看结果；确认后启用定时任务。

不需要手填游戏 Cookie。每轮从 MP 站点记录读取最新 Cookie，并复用该站点的 User-Agent。旧版手填的 cookie 配置不再使用，保存新配置时移除该字段。

游戏公开页面“从主站登录”指向 https://www.tangpt.top/parking.php 。插件进入所选主站的 /parking.php，跟随服务端重定向、SSO iframe、Meta Refresh 或字面量 JavaScript 跳转，使用会话 CookieJar 接收游戏回调的 Set-Cookie，最后读取游戏状态确认认证有效。仅打开页面或带有 userId 参数不能证明认证成功。

主站 Cookie 只预置到所选主站域名，游戏请求使用登录回调设置的 Cookie；不把主站 Cookie 放入全局请求头或复制到游戏域名。只接受已知主站和游戏的 HTTPS 跳转，不记录 Cookie、SSO票据、跳转URL或响应正文。

主站 Cookie 过期时，在 MP 站点管理更新，下轮会读取新值。如果首次 SSO 需要手动授权、验证码或未支持的脚本/表单，插件会停止；先在普通浏览器从主站完成必要步骤。插件不执行任意 JavaScript、不填写登录表单，也不自动接受新增授权。

## 操作节奏和结果

- 10秒间隔覆盖全部 HTTP 请求，包括主站登录跳转、状态读取、贴条、收车、停车。按响应完成时间计时，慢请求返回后也要等待完整间隔。
- 连接超时15秒，响应读取超时90秒。请求失败、限流、业务拒绝或操作结果未确认时停止本轮；不盲目重试可能已经成功的 POST，下轮重新认证并读取状态。
- 每次操作前重新核对账号、归属、收益、车位和主人等级/金币，之后读回状态确认结果。服务端仍可能在请求间发生并发变化，最终由游戏服务端裁定。
- 多辆车或登录跳转较多时，一轮可能超过5分钟；任务互斥，不会叠加执行。禁用/重载插件会中断等待，已提交请求需要等待返回，已提交操作不能撤回。
- 结果页保留最近20轮的时间、状态、贴条次数、收车数、停车数、到账金币和剩余空闲数。
- 使用 GET /api/game_data.php、GET /api/state.php，以及 POST /api/ticket.php（spotId）、POST /api/unpark.php（userCarId）、POST /api/park.php（userCarId、spotId）。不写入 state.php，不举报、买卖车辆、兑换魔力或发聊天消息。

## 安装与验证

插件市场条目 QcwAutoPark，目录 qcwautopark。V2/V3实现保持同步。当前修改未自动推送或部署。

已核对公开登录入口、前端接口参数及公开车型/停车规则。离线测试覆盖认证跳转、Cookie域隔离、10秒节流与停止、贴条包含边界、私家/爱心/自己/他人车位隔离、双条件筛选、状态确认和异常停止。

尚未使用用户 MP 内的有效主站 Cookie 完成真实 SSO 和游戏操作联调。部署后先执行一次；如遇未支持的登录跳转，需要根据实际响应继续适配。

```bash
python3 -m unittest discover -s tests/qcwautopark -v
```
