# 馒头保活助手（mtaliver）

首次使用账号密码和手动邮箱验证码登录，保存浏览器 Cookie、localStorage、sessionStorage，以后每天打开站点首页。容器重启后可从插件数据恢复会话；修改账号、密码或站点地址后，需要重新验证。

## 安装和首次验证

1. 在 MoviePilot 插件市场添加本仓库 `https://github.com/tmzg0000/MoviePilot-Plugins`，刷新后安装「馒头保活助手」。
2. 填写 M-Team **账号、密码、绑定邮箱**；确认账号允许邮箱验证。
3. 勾选「发送邮箱验证码」并保存。插件会通过站点登录页发送一次邮件；结果显示等待验证。
4. 收到邮件后，填写「邮箱验证码」并保存即可触发登录。**不要再次勾选发送验证码**，避免旧验证码失效。验证码为 6 位数字，提交后自动从配置清空，失败时需重新填写或重新发码。
5. 登录成功后开启插件和通知。默认 Cron 为 `35 1,9,21 * * *`，按 MoviePilot 时区每天 01:35、09:35、21:35 检查是否需要保活。同日成功后自动任务跳过；「立即执行一次」可强制访问。

保存后，结果页顶部会显示「任务已排队」或「正在提交邮箱验证码」；稍后重新打开结果页查看完成记录。若一直排队未执行，可重新保存配置重试。收到邮件后的验证码会按站点规则过期，等待过久时需要重新发码。

插件不会定时发送验证码。会话失效时会报告失败，开启通知后提示重新验证。站点若要求再次验证，就仍需手工填码，无法保证永久只验证一次。

## 浏览器和校验

需要 MoviePilot 本地 Playwright 浏览器及 `PlaywrightHelper.action()`；容器必须能连接站点与 `static.m-team.cc`。站点页面结构改变、安全验证或网络限制可能导致登录失败。没有浏览器依赖时插件会给出失败原因，不会自动安装环境。

可选填写 API Key，或自动使用 MoviePilot 站点管理的 M-Team API Key。默认开启「最近动向」校验：浏览器须收到有效账号响应，同时最近动向须比执行前更新且处于配置时间窗口内。有 Key 但统计接口失败时，会报告无法确认；关闭校验或没有 Key 时，仅能证明网页会话有效。API 统计请求不作为网页访问成功的依据，也不能把浏览器失败改为成功。

**复用会话访问是否满足 M-Team 当前保号规则，需要部署后检查「最近浏览/最近登录」及站点规则。**上游描述其环境中复用会话没有刷新活动时间；本版本不能承诺每日访问就能重置删号计时。未使用真实账号进行线上登录测试。

## 凭据存储

账号密码按 MoviePilot 插件配置保存；浏览器会话在插件数据 `browser_state` 中保存，包含登录凭据。不要分享配置/数据备份。验证码不写入日志、历史或结果页；会话不在配置表单或结果页显示。卸载时可选择删除插件配置和数据。

本地模拟测试：`python3 -m unittest discover -s tests/mtaliver -v`。
