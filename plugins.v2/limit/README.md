支持为 qBittorrent 和 Transmission 设置全局上传限速与按标签上传限速，支持 Cron、固定间隔和运行一次。覆盖模式控制是否覆盖已有的种子限速。标签规则每行一条，格式为 `标签:速度`，使用英文冒号，留空则不按标签限速。

## 所有种子限速

1. 选择下载器，将「种子限速方式」设为「所有种子限速」。
2. 填写「每个种子上传限速(KiB/s)」，例如 `3000` 表示每个种子各自限制为 `3000 KiB/s`，`0` 表示取消种子限速。
3. 要覆盖已有种子上限或取消已有上限，请开启「覆盖模式」；关闭时跳过已有限速的种子。
4. 选择「运行一次」应用设置，或启用插件并配置定时执行，处理后续添加的种子。

此模式处理所选下载器的所有种子，包括没有标签的种子，不使用标签规则，也不调用下载器全局限速接口。已有的下载器全局上限仍会影响实际传输速度。旧配置默认继续使用按标签模式。

### 新增与全部筛选

「仅处理新增种子」默认关闭，只在所有种子模式中生效，计划任务、固定间隔和运行一次使用相同规则：

- 关闭：每次扫描下载器全部种子；覆盖模式关闭时仍跳过已有限速的种子。
- 开启：按下载器类型、名称和种子 hash 保存记录，后续只处理未记录的种子。记录持久化，重启与保存配置不会重置。
- 首次成功扫描若无该下载器的历史记录，只记录已有种子，不修改其限速；之后新出现的种子才限速。此前在全部模式下已有扫描记录时，直接沿用记录。
- 新增种子限速失败会在下一轮重试；获取种子列表失败时保留原记录。成功扫描时移除已删除种子的记录，之后重新添加可再处理。
- 改速度不会重新设置已记录的旧种子。要给全部种子应用新上限，关闭新增筛选、开启覆盖模式并运行一次；之后可重新开启新增筛选。

此处“新增”指自上次扫描后首次出现的 hash；同一 hash 在两次扫描之间删除并重新添加，无法仅凭扫描记录区分。

## 单位与升级

所有配置项和日志统一使用 **KiB/s**，`1 KiB/s = 1024 B/s`，`0` 表示不限速。例如 `PT:30000` 代表为带 `PT` 标签的种子设置 `30000 KiB/s`（约 `29.3 MiB/s`）的上传上限。

- qBittorrent 标签及所有种子限速：配置值乘以 `1024` 后传给接收 B/s 的原生接口。
- qBittorrent 全局限速：配置值直接传给 MoviePilot 接口，由 MoviePilot 内部换算，避免重复乘以 `1024`。
- Transmission 标签、所有种子及全局限速：配置值乘以 `1024 / 1000`，向下取整后传给接收整数 kB/s 的接口；实际上限与配置值差距小于 `1000 B/s`。

从 `1.1.5` 更新后，已保存的数字按 KiB/s 解释，不自动改写。此前若放大数字来补偿 qB 标签限速错误，请按目标 KiB/s 重新填写。应用到已有限速的种子时，开启「覆盖模式」并选择「运行一次」。
